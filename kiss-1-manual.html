はじめにIntroduction INTRODUCTION

KISS-1 は、ネットワークのタリーと DB25 の接点（GPI / GPO）を相互に変換するハーフラック 1U の機材です。設定はすべてブラウザの設定ページから行います。この説明書はファーム v0.7.7 に合わせています。

KISS-1 is a half-rack 1U unit that converts between network tally and DB25 contacts (GPI / GPO) in both directions. Everything is set up from a settings page in a web browser. This manual covers firmware v0.7.7.

できることWhat it does

  • タリーを受けて接点で出す：ATEM・TSL 5.0 からタリーを受け、DB25 の GPO を赤（PGM）・緑（PVW）で点けます。Tally in, contacts out: takes tally from ATEM or TSL 5.0 and lights DB25 GPOs red (PGM) and green (PVW).
  • 接点を受けてネットワークへ送る：DB25 の GPI で受けた接点を、TSL 5.0 で別の機器（もう 1 台の KISS-1 や LORA-TALLY 親機など）へ送ります。Contacts in, network out: contacts received on DB25 GPIs are sent as TSL 5.0 to other gear (another KISS-1, a LORA-TALLY base unit and so on).
  • ピンを自由に割り当てる：DB25 の 25 本のピンを、GPI・GPO・COM・GND・+5V などに 1 本ずつ割り当てられます。Assign every pin: each of the 25 DB25 pins can be set as GPI, GPO, COM, GND, +5 V and more.
  • +5V を出す：COM を +5V にすると、ランプやリモコンに +5V を出せます（合計 5A まで）。+5 V out: with COM set to +5 V, the unit can power lamps and remote panels (up to 5 A in total).
  • 本体の上でスクリプトを動かす：Arduino と同じ書き方のプログラムを設定ページで書き、本体で実行できます。Scripts on the unit: write Arduino-style programs on the settings page and run them on the unit.
  • 汎用 GPIO として使う：タリー以外の接点の中継にも使えます（「使い方」で切り替え）。General-purpose GPIO: it can also relay contacts that have nothing to do with tally (switch with "Use").

接続Connecting CONNECTING

電源は DC から入れ、LAN と DB25 をつなぐだけで使えます。

Power it from DC and connect LAN and DB25 — that is all.

電源Power

  • 普段は DC 入力（DC 9〜24V、最大 36W）から入れます。+5V を出す使い方も DC が前提です。Normally power it from the DC input (DC 9–24 V, 36 W max). The +5 V output also needs DC power.
  • USB-C はファームの書き込み用です。USB-C is for flashing firmware.
  • 電源を入れると、状態 LED が青になり、数秒で緑かオレンジに変わります。At power-on the status LED turns blue, then green or orange after a few seconds.

LANLAN

  • スイッチャーや PC と同じネットワークにつなぎます（10/100 Mbps）。Connect it to the same network as the switcher and PC (10/100 Mbps).
  • LAN がつながっていないと、状態 LED が赤で点滅します。With no LAN link, the status LED blinks red.

DB25DB25

  • 市販のアナログオーディオ用 DB25-XLR ケーブル（TASCAM 配列）がそのまま使えます。Off-the-shelf analog audio DB25-XLR cables (TASCAM pinout) work as they are.
  • 工場出荷の割り当てでは、XLR の 1〜8 番が CAM 1〜8 になります。With the factory assignment, XLR 1–8 are CAM 1–8.
XLR のピンXLR pin割り当てAssignment
11COMCOM
22PGM（赤）PGM (red)
33PVW（緑）PVW (green)
  • 工場出荷では全部 GPI（入力）です。タリーを点ける側（GPO）で使うときは、「ピン割り当て」で内蔵プリセットを「GPO として読み込む」にします。From the factory they are all GPI (inputs). To drive tally lamps (GPO), load the built-in preset with "Load as GPO" on the pins page.
  • インカムなど、電圧が乗っているラインにはつながないでください。Do not connect lines that carry voltage, such as intercom lines.

はじめて使うGetting started FIRST USE

工場出荷の IP は 192.168.10.90（固定）です。PC を同じネットワークにして、ブラウザで開きます。

The factory IP is 192.168.10.90 (fixed). Put your PC on the same network and open it in a browser.

  1. KISS-1 と PC を LAN でつなぎ、KISS-1 の電源を入れます。Connect KISS-1 and the PC by LAN and power on KISS-1.
  2. PC の IP を 192.168.10.x（.90 以外、例：192.168.10.10）、サブネットマスクを 255.255.255.0 にします。Set the PC to 192.168.10.x (not .90, e.g. 192.168.10.10) with subnet mask 255.255.255.0.
  3. ブラウザで http://192.168.10.90 を開きます。Open http://192.168.10.90 in a browser.
  4. 「設定と状態」のページが出たら、使う現場に合わせて「ネットワーク」の IP を変えます。変えた IP は再起動すると切り替わります。On the "Settings and status" page, change the IP under "Network" to suit the site. A new IP takes effect after a restart.
  5. 「タリーの入力元」と「ピン割り当て」を設定して、「保存して反映」を押します。Set the tally source and the pin assignment, then press "Save and apply".

ページは 3 つあり、上のメニューで切り替えます。

There are three pages; switch between them with the menu at the top.

設定ページ（設定と状態）Settings page (Settings and status) SETTINGS

変えたら「保存して反映」を押すと、すぐに切り替わります。ネットワークだけは再起動で切り替わります。

Changes take effect as soon as you press "Save and apply". Only the network settings need a restart.

タリーと状態Tally and status

  • ページの上に、各カメラのタリー（赤・緑）が表示されます。The tally of each camera (red / green) is shown at the top of the page.
  • 「状態」には、入力元・TSL 受信・TSL 送信・I/O 基板・電源・設定の読み込み元・稼働時間とファームのバージョンが出ます。"Status" shows the source, TSL in, TSL out, I/O board, power, where the settings were loaded from, uptime and firmware version.

使い方とタリーの色Use and tally colour

  • 「使い方」：「タリー」はカメラ番号と赤・緑で、「汎用 GPIO」は信号番号で表示します。中の動きは同じです。"Use": "Tally" shows camera numbers in red and green, "General GPIO" shows signal numbers. Inside it works the same.
  • 「タリーの色」：「RED + GREEN」か「RED のみ」。RED のみにすると PVW（緑）は使わず、GPO・TSL 送信もすべて赤だけになります（内蔵プリセット「連番 24ch（RED のみ）」と組み合わせると 24 カメラまで）。"Tally colour": "RED + GREEN" or "RED only". With RED only, PVW (green) is not used and GPOs and TSL out are red only (up to 24 cameras with the built-in preset "Sequential 24ch (RED only)").

TSL 5.0 送信TSL 5.0 out

受けたタリー（GPI を含む）を TSL 5.0 で送ります。LORA-TALLY 親機や、もう 1 台の KISS-1 へつなぐときに使います。

Sends the tally it has (GPIs included) as TSL 5.0. Use it to feed a LORA-TALLY base unit or another KISS-1.

  • 送り方：UDP / TCP（こちらから接続）/ TCP（こちらで待ち受け）。Transport: UDP / TCP (connect) / TCP (listen).
  • UDP の送り先：「1 台に送る」「全体に送る」（255.255.255.255）「マルチキャスト」（迷ったら 239.1.1.1）。UDP destination: "One unit", "Broadcast" (255.255.255.255) or "Multicast" (239.1.1.1 if unsure).
  • 「くり返し送信 ms」：変化がなくてもこの間隔で送り直します（50〜60000）。0 にすると変化したときだけ送ります。"Resend ms": resends at this interval even without changes (50–60000). 0 sends only on a change.
  • CAM1 の TSL 番号（INDEX）、SCREEN、点けるランプ（RH・TEXT・LH）を相手に合わせます。Match the TSL number for CAM1 (INDEX), SCREEN and the lamps (RH, TEXT, LH) to the receiver.

ネットワークNetwork

  • IP アドレス・サブネットマスク・ゲートウェイ。「DHCP で自動取得する」も選べます。IP address, subnet mask and gateway. "Get automatically by DHCP" is also available.
  • 「保存して反映」のあと、「再起動して切り替える」で切り替わります。再起動中の数秒間は、GPO がすべて OFF になり、タリーも止まります。After "Save and apply", press "Restart to switch". For a few seconds while it restarts, all GPOs are off and tally stops.

設定のプリセットSettings presets

  • 今の設定（入力元・TSL・使い方・ピン割り当てなど）に名前を付けて保存します。Save the current settings (source, TSL, use, pin assignment and more) under a name.
  • 保存先：本体に 8 個、microSD に何個でも、PC にファイルで。Where: 8 in the unit, any number on the microSD, or as a file on the PC.
  • KISS-1 自身の IP などのネットワーク設定は含みません。そのため、別の台に読み込んでも IP は変わりません。ATEM や TSL の送り先など「相手の IP」は含みます。Presets do not include the unit's own network settings, so loading one on another unit never changes its IP. The IPs of other gear (ATEM, TSL destination and so on) are included.
  • 先に「保存して反映」を押してから保存してください。読み込むと、その場で反映されます。Press "Save and apply" before saving a preset. Loading a preset applies it immediately.
  • 「今の設定ファイルをダウンロード」で、ネットワークも含む全部の設定（kiss1.txt）を PC に保存できます。"Download the current settings file" saves all settings, network included (kiss1.txt), to the PC.

工場出荷に戻すFactory reset

  • 1 回押すと「本当に戻す？」に変わり、4 秒以内にもう一度押すと実行します。Press once and it asks "Really reset?"; press again within 4 seconds to do it.
  • 本体に保存した設定（ネットワークを含む）・設定とピンのプリセット・スクリプトを消して再起動し、192.168.10.90 で立ち上がります。It erases the settings stored in the unit (network included), the settings and pin presets and the script, then restarts at 192.168.10.90.
  • microSD の中身は消しません。kiss1.txt は kiss1_old.txt に名前を変えて残します。The microSD is not erased; kiss1.txt is renamed to kiss1_old.txt.

ファームの更新Firmware update

  • 本体だけの .bin（例：KISS1_FW.ino.bin）を選んで「アップデート」を押します。merged.bin は使えません。Choose the application-only .bin (e.g. KISS1_FW.ino.bin) and press "Update". merged.bin cannot be used.
  • 設定は残ります。更新中はタリーと GPO が止まり、状態 LED が紫で点滅します。Settings are kept. During the update, tally and GPOs stop and the status LED blinks purple.
  • 失敗したときは、今のファームのまま動き続けます。If it fails, the unit keeps running the current firmware.

ピンの設定（ピン割り当て）Pin setup (Pins page) PINS

DB25 の 25 本のピンに、使い方とカメラ番号・色を 1 本ずつ割り当てます。変えたら「保存して反映」で切り替わります。

Give each of the 25 DB25 pins a role, a camera number and a colour. Changes take effect with "Save and apply".

ページの上の DB25 の絵は背面から見た向きです。ピンを押すと、下の表のその行に移ります。「状態」の欄には、今のピンの状態がタリーの色で出ます。

The DB25 drawing at the top is seen from the rear. Click a pin to jump to its row in the table. The "State" column shows the current state of each pin in tally colour.

COM を +5V にするときの安全策Safety when COM goes to +5 V

COM を +5V に切り替えると、今 COM になっているピンはいったんすべて GND に変わります。COM につないであった機器に、いきなり +5V がかからないようにするためです。

When COM is switched to +5 V, every pin that is currently COM turns into GND first, so gear wired to COM never suddenly gets +5 V.

  • +5V を出したいピンは、そのあと自分で「+5V」に選び直します。Then choose "+5V" again yourself for the pins that should carry +5 V.
  • ピンのプリセット・設定のプリセット・microSD の kiss1.txt で +5V に切り替わる場合も、同じように GND に変わります。The same happens when a pin preset, a settings preset or kiss1.txt on the microSD switches COM to +5 V.

プリセットPresets

  • 内蔵：アナログオーディオケーブル（TASCAM DB25-XLR）、Hollyland ワイヤレスタリー、連番 24ch（RED のみ）、連番 12ch（RED + GREEN）。それぞれ「GPI として」「GPO として」読み込めます。Built in: analog audio cable (TASCAM DB25-XLR), Hollyland wireless tally, sequential 24ch (RED only), sequential 12ch (RED + GREEN). Each can be loaded "as GPI" or "as GPO".
  • 保存したもの：今の割り当てに名前を付けて 8 個まで保存できます。Saved: up to 8 of your own assignments, by name.
  • 読み込んだだけでは反映されません。「保存して反映」で切り替わります。Loading alone does not apply it; press "Save and apply".

セルフテストSelf test

DB25 のケーブルを外して「セルフテストを実行」を押すと、約 3 秒で全ピンの出力と入力、+5V、LAN、microSD、DC 入力電圧を調べます。テスト中は全ピンを順に COM・GND・+5V へつなぐので、必ずケーブルを外してから実行してください。

Unplug the DB25 cable and press "Run self test": in about 3 seconds it checks the outputs and inputs of every pin, +5 V, LAN, microSD and the DC input voltage. During the test every pin is connected in turn to COM, GND and +5 V, so always unplug the cable first.

スクリプトScripts SCRIPT

Arduino と同じ書き方（setup() と loop()）のプログラムを、「スクリプト」のページで書いて本体の上で動かせます。PC でのコンパイルやファームの書き込みはいりません。

Write a program the Arduino way (setup() and loop()) on the Script page and run it on the unit. No compiling on a PC and no firmware flashing.

使い方How to use

  1. 「ピン割り当て」で、スクリプトから動かしたいピンを SCRIPT にします。On the Pins page, set the pins the script should drive to SCRIPT.
  2. 「例を入れる…」から近い例を選ぶか、自分で書きます。Pick a close example from "Insert example…" or write your own.
  3. 「検証」で書き方を確かめ、「保存して実行」で動かします。「停止」で止めます。"Check" verifies the code, "Save and run" runs it, "Stop" stops it.
  4. 「電源を入れたら自動で実行」にチェックすると、起動のたびに動きます。Tick "Run automatically at power-on" to run it every time the unit starts.
  • Tab で字下げ、Ctrl+S で保存、Ctrl+Enter で保存して実行。「PC から開く」「PC に保存」でファイルにもできます。Tab indents, Ctrl+S saves, Ctrl+Enter saves and runs. "Open from PC" and "Save to PC" work with files.
  • 長さは 16KB まで。計算はすべて 32 ビットの整数で、float・String・ポインタは使えません。Up to 16 KB. All maths is 32-bit integer; float, String and pointers are not available.
  • 停止したときやエラーのときは、SCRIPT のピンはすべてオフになり、タリーの上書きも解除されます。When the script stops or hits an error, all SCRIPT pins turn off and tally overrides are released.
  • 電源を入れるときに SW3（USER）を押していると、自動実行しません。スクリプトのせいでおかしくなったときに使います。Holding SW3 (USER) at power-on skips the automatic run — use it if a script has made things go wrong.

microSD からのファーム更新Firmware update from microSD

  1. 本体だけの .bin を、「KISS1」で始まり「.bin」で終わる名前（例：KISS1_FW.bin）で microSD の直下に置きます。Put the application-only .bin in the root of the microSD with a name that starts with "KISS1" and ends with ".bin" (e.g. KISS1_FW.bin).

Settings are kept. To reuse the card, rename the .done file back before putting it in the next unit.

USB での書き込みFlashing over USB

設定ページが開けないときや、新品の状態から入れ直したいときの方法です。フラッシュを全部消すと、本体の設定・プリセット・スクリプトも消えます。

Use this when the settings page won't open or to reinstall from scratch. Erasing the flash also erases the unit's settings, presets and script.

  1. 上フタを外し、PC と USB-C でつなぎます。Remove the top cover and connect the PC by USB-C.
  2. SW2（BOOT）を押したまま SW1（EN）を押して離し、そのあと SW2 を離します。Hold SW2 (BOOT), press and release SW1 (EN), then release SW2.
  3. Chrome で Adafruit WebSerial ESPTool を開き、「Connect」で COM ポートを選びます。Open Adafruit WebSerial ESPTool in Chrome and choose the COM port with "Connect".
  4. 「Erase」で全部消します。Press "Erase" to erase everything.
  5. 1 段目の Offset を 0 にして KISS1_FW.ino.merged.bin を選び、「Program」を押します。Set the first Offset to 0, choose KISS1_FW.ino.merged.bin and press "Program".
  6. 終わったら SW1 を押して再起動します。IP は 192.168.10.90 になります。When finished, press SW1 to restart. The IP is 192.168.10.90.

COM ポートが出てこないときは、別の USB ケーブル（データ通信できるもの）も試してください。

If no COM port appears, try another USB cable (one that carries data).
